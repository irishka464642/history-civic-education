# Практикум «Реформи Русі-України»

Інтерактивний сайт для 10 класу поглибленого рівня інтегрованого курсу історії та громадянської освіти.

## Зміст
- Порівняння реформ княгині Ольги, Володимира Великого, Ярослава Мудрого, Володимира Мономаха.
- Первинні уривки з літописної традиції та правових / повчальних джерел із застереженнями щодо інтерпретації.
- Державні дилеми 945 і 1113 рр., оцінка довготривалих наслідків.
- Інтерактивний тест (8 запитань), аргументований висновок, самооцінювання за 12-бальною рубрикою.
- Локальне збереження й експорт TXT. Додатково — онлайн-надсилання у приватну Google-таблицю зі сповіщенням на пошту після одноразового налаштування Google Apps Script. Без власного сервера та облікових записів для учнів.

## Джерельна основа
1. Модельна навчальна програма «Інтегрований курс історії та громадянської освіти. 10–12 класи. Поглиблений рівень», розділ «Людина і влада», сторінки PDF 12–14.
2. І. Щупак та ін., «Історія та громадянська освіта», 10 клас, поглиблений рівень, розділи про ранню Русь і княжу добу, сторінки PDF 305–311, 327–329. Уривки в практикумі цитуються за наданим навчальним текстом.

Файли повних підручників на GitHub **не завантажувалися**. Це окремий навчальний застосунок з невеликими цитованими фрагментами.

## Проведення
Орієнтовно два уроки по 45 хв:
- Вступ і порівняння — 20 хв.
- Джерела — 25 хв.
- Дилеми — 15 хв.
- Післядія, тест і рефлексія — 30 хв.

Можлива індивідуальна і парна робота. Тренувальний тест **не замінює** оцінювання роботи з джерелами.

## Розміщення
Статичний HTML/CSS/JavaScript. Сайт публікується на GitHub Pages через наявний у репозиторії workflow.

Відносна адреса: \`/history-civic-education/Історія%20та%20ГО/reformy-rusi/\`.

## Локальний перегляд
Відкрийте \`index.html\` у браузері. Файли \`styles.css\` і \`app.js\` повинні лежати поруч.

## Налаштування онлайн-збору робіт (потрібна одноразова дія власника Google-акаунта)

Сайт працює як статичний GitHub Pages. Він **не має доступу до пошти вчителя або Google Drive без окремої авторизації**. Для приймання даних використовується Google Apps Script, який створює приватну таблицю та надсилає e-mail.

1. Увійдіть у потрібний Google-акаунт і відкрийте [script.google.com](https://script.google.com). Натисніть **Новий проєкт**.
2. Відкрийте [google-apps-script/Code.gs](./google-apps-script/Code.gs). Скопіюйте **весь** код у файл `Code.gs` свого нового проєкту.
3. У параметрі `NOTIFY_EMAIL` (на початку коду) замініть `ВСТАВТЕ_СВОЮ_EMAIL_АДРЕСУ` на адресу, куди мають приходити роботи. **Не публікуйте її у GitHub.**
4. У верхньому списку функцій оберіть `setup`, натисніть **Run / Виконати**, схваліть запит Google на доступ до таблиць і надсилання листів. Після запуску скрипт створить **приватну** Google-таблицю «Реформи Русі-України — відповіді учнів». Її посилання з’явиться у **Execution log / Журнал виконання**.
5. Натисніть **Deploy → New deployment → Web app**. Виберіть **Execute as: Me / Виконувати від мого імені**, **Who has access: Anyone / Усі**. Якщо у шкільному Workspace анонімний доступ заборонений, використайте Google-акаунт, у якому це дозволено, або погодьте інший спосіб з адміністратором.
6. Скопіюйте URL **Web app** з кінцівкою `/exec`. Відкрийте [submission-config.js](./submission-config.js) у GitHub, натисніть «Edit this file» і замініть порожнє значення на цей URL:
   ```js
   window.PRACTICUM_SUBMISSION_ENDPOINT = 'https://script.google.com/macros/s/ВАШ_ID/exec';
   ```
   Збережіть зміни (Commit). Дочекайтеся успішного workflow **Publish educational sites**.
7. Відкрийте сторінку практикуму, заповніть тестову роботу та натисніть **Надіслати роботу вчителю**. **Обов’язково перевірте**, що рядок з’явився в таблиці, а лист надійшов у потрібну скриньку (за потреби в папку «Спам»). Після тесту видаліть тестовий рядок.

### Що зберігається

У приватній таблиці: час, ім’я та прізвище, клас/група, результат тренувального тесту, відсоток заповнення, повний текст відповідей, технічний ID запиту та стан e-mail сповіщення. На обрану адресу приходить повідомлення з цим текстом.

Учні не входять у Google-акаунти. Сайт не запитує їхніх електронних адрес, телефонів, домашніх адрес або паролів. **Повідомте учням та батькам** про збирання й призначення даних, а доступ до Google-таблиці залишайте обмеженим. Перед використанням із неповнолітніми узгодьте процедуру з політикою вашого закладу освіти.

### Особливості та захист

- Endpoint є публічним і може отримувати запити з Інтернету; у скрипті є базова перевірка даних, приховане пасткове поле та механізм проти випадкових повторів, але це **не CAPTCHA і не повноцінний захист від спаму**.
- Квоти Google Apps Script/MailApp можуть обмежувати кількість листів; записи в таблиці лишатимуться основним каналом збору.
- Через обмеження CORS запит `fetch(..., {mode:'no-cors'})` не дозволяє сайту перевірити справжню відповідь сервера. Тому сайт **не показує неправдивого підтвердження доставки**; результат слід перевірити в таблиці.
- Якщо скрипт редагується, нову версію слід **перепублікувати в Manage deployments** для роботи з URL `/exec`.
- Google-таблиця та серверний код скрипту мають залишатися приватними. У GitHub зберігаються тільки шаблон і URL публічного приймача.
