# Практикум «Реформи Русі-України»

Інтерактивний сайт для 10 класу поглибленого рівня інтегрованого курсу історії та громадянської освіти.

## Зміст
- Порівняння реформ княгині Ольги, Володимира Великого, Ярослава Мудрого, Володимира Мономаха.
- Первинні уривки з літописної традиції та правових / повчальних джерел із застереженнями щодо інтерпретації.
- Державні дилеми 945 і 1113 рр., оцінка довготривалих наслідків.
- Інтерактивний тест (8 запитань), аргументований висновок, самооцінювання за 12-бальною рубрикою.
- Локальне збереження й експорт TXT. Онлайн-надсилання повної роботи безпосередньо на пошту вчителя після одноразового налаштування Google Apps Script; **без Google Таблиць і без облікових записів для учнів**.

## Джерельна основа
1. Модельна навчальна програма «Інтегрований курс історії та громадянської освіти. 10–12 класи. Поглиблений рівень», розділ «Людина і влада», сторінки PDF 12–14.
2. І. Щупак та ін., «Історія та громадянська освіта», 10 клас, поглиблений рівень, розділи про ранню Русь і княжу добу, сторінки PDF 305–311, 327–329. Уривки в практикумі цитуються за наданим навчальним текстом.

Файли повних підручників на GitHub **не завантажувалися**. Це окремий навчальний застосунок з невеликими цитованими фрагментами.

## Проведення
Орієнтовно два уроки по 45 хв:
- Вступ і порівняння — 20 хв.
- Джерела — 25 хв.
- Дилеми — 15 хв.
- Післядія, тест і рефлексія — 30 хв.

Можлива індивідуальна і парна робота. Тренувальний тест **не замінює** оцінювання роботи з джерелами.

## Розміщення
Статичний HTML/CSS/JavaScript. Сайт публікується на GitHub Pages через наявний у репозиторії workflow.

Відносна адреса: \`/history-civic-education/Історія%20та%20ГО/reformy-rusi/\`.

## Локальний перегляд
Відкрийте \`index.html\` у браузері. Файли \`styles.css\` і \`app.js\` повинні лежати поруч.

## Одноразове підключення надсилання **тільки на пошту**

GitHub Pages — статичний сайт, тому для автоматичного відправлення листів потрібен окремий Google Apps Script. Його код у цьому репозиторії — **шаблон**, а не вже активний поштовий сервер. Ніяких таблиць, баз даних або акаунтів учнів немає.

1. Увійдіть до свого Google-акаунта, на який отримуватимете роботи, і відкрийте [Google Apps Script](https://script.google.com). Натисніть **«Новий проєкт»**.
2. Перейдіть до [google-apps-script/Code.gs](./google-apps-script/Code.gs), скопіюйте весь текст і замініть ним вміст файлу **Code.gs** у вашому **приватному** Apps Script.
3. У верхній частині коду замініть значення \`EMAIL_TO\` на свою реальну адресу електронної пошти у лапках. **Не редагуйте цей параметр на публічному GitHub** — пошта буде у вашому приватному Apps Script.
4. У меню функцій виберіть \`authorizeMail\` і натисніть **Run / Виконати**. Надайте Google запитані дозволи для MailApp. Має надійти **тестовий лист** на вашу пошту (за потреби перевірте «Спам»).
5. Оберіть **Deploy / Розгорнути → New deployment / Нове розгортання → тип Web app / Вебзастосунок**. Оберіть **Execute as: Me / Виконувати від мого імені** та **Who has access: Anyone / Доступ: усі**. Якщо у вашому акаунті цієї опції немає, перевірте політику доступу з адміністратором Google Workspace. Скопіюйте URL із закінченням \`/exec\`.
6. У GitHub відкрийте [submission-config.js](./submission-config.js), натисніть кнопку редагування й вставте цей URL в лапках замість порожнього рядка:
   \`\`\`js
   window.PRACTICUM_SUBMISSION_ENDPOINT = 'https://script.google.com/macros/s/ВАШ_ID/exec';
   \`\`\`
   Збережіть зміни (Commit). GitHub Pages опублікує оновлення через наявний workflow.
7. Перевірте на сайті тестову учнівську роботу: ім’я, клас, принаймні одну письмову відповідь, згода на передавання, кнопка **«Надіслати роботу вчителю»**. Перевірте реальну доставку листа у Gmail. Сам сайт через обмеження браузера не може підтвердити її достовірно.

### Що саме приходить у листі

- Тема: \`Практикум Русі — 10-А — Ім'я та прізвище\`
- Тіло: ім’я і клас, час, результат тренувального тесту, заповнені відповіді з усіх етапів.
- Пошти, телефонів, адрес або паролів учнів сайт не запитує.
- Оригінальні відповіді також зберігаються локально у браузері учня, доки він їх сам не очистить.

### Важливі обмеження

- **Google Таблиці не створюються й не використовуються.** Єдиний централізований канал отримання робіт — електронна пошта.
- Публічний вебзастосунок може отримувати сторонні запити; є базова перевірка полів і пастка для ботів, але це **не повний захист від спаму**.
- Gmail / Apps Script мають денні квоти на надсилання листів. Якщо ліміт вичерпано, лист може не надійти. Учень завжди може зберегти TXT як резервну копію.
- Через CORS сайт не може перевірити результат відправлення, тому повідомляє тільки про виконаний запит. Після тестового надсилання **обов’язково перевірте Gmail**.
- Якщо відредагувати приватний Apps Script після публікації, оновіть активне розгортання через **Manage deployments / Керувати розгортаннями**.
- Перед збиранням даних неповнолітніх повідомте учнів і батьків про мету та склад отримуваної інформації; зберігайте листи в пошті, доступ до якої належно обмежено.
