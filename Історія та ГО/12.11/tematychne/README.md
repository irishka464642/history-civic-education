# Тематичне оцінювання · окремий сайт

Цей сайт знаходиться окремо від навчального архіву, у папці `Історія та ГО/12.11/tematychne/`.

- [Сторінка для учнів](https://irishka464642.github.io/history-civic-education/Історія%20та%20ГО/12.11/tematychne/)
- 12 однотипних завдань з вибором однієї відповіді, загалом 12 балів.
- Індивідуальні результати (ім’я, клас, 12 відповідей, бал, дата) мають потрапляти у **приватну Google Таблицю**.
- **Важливо:** зберігання ще НЕ підключене. Кнопку надсилання заблоковано, доки в `index.html` не налаштований `RESULTS_ENDPOINT`.
- Для підключення створіть Google Apps Script у своєму акаунті, вставте приватний серверний скрипт, запустіть `setup()`, розгорніть як вебзастосунок (Execute as: Me; Access: Anyone) і додайте отриманий URL `/exec` в `RESULTS_ENDPOINT`.
- **Не публікуйте скрипт із ключем відповідей у відкритому репозиторії.** Він має залишатися тільки у вашому приватному проєкті Apps Script.

**Обмеження:** сам по собі статичний сайт GitHub Pages не може безпечно зберігати оцінки. Відкритий Apps Script приймає відправлення без входу в Google, тому не засвідчує особу учня: для формального високоставкового контролю потрібні додаткові заходи (шкільний вхід, нагляд, індивідуальні коди тощо). Запитання стосуються історії ранньосередньовічних держав із практикуму; за потреби тематичного охоплення всього розділу тест слід розширити.
