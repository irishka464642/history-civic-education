# Архів влади — практикум на 12.11

Інтерактивне заняття для 10 класу (поглиблений рівень): дослідження форм державної влади за справжніми середньовічними джерелами.

## Як користуватися
- Відкрити `index.html` у браузері або перейти на сайт через GitHub Pages після ввімкнення публікації.
- Учні читають чотири навчальні адаптації історичних документів, відповідають на питання й працюють з історичним атласом.
- У нижній частині сайту заповнюють порівняльну таблицю та висновок.
- Кнопка **«Зберегти відповіді (.txt)»** завантажує їх на пристрій. Автоматичного надсилання вчителю немає.
- Введені відповіді за можливості зберігаються локально у браузері.

## Історичні джерела
1. [Карл Великий, Капітулярій 802 р.](https://sourcebooks.fordham.edu/source/802Charlemagne-capitulary.asp)
2. [Юстиніан I, передмова до «Інституцій», 533 р.](https://droitromain.univ-grenoble-alpes.fr/Anglica/just_proem_Moyle.htm)
3. [«Літопис руський» / «Повість минулих літ», розповідь про Ярослава](https://litopys.org.ua/litop/lit07.htm)
4. [Альфред Великий, передмова до законів, бл. 890 р.](https://avalon.law.yale.edu/medieval/saxlaw.asp)

**Примітка:** тексти на сайті — адаптовані перекази, не дослівні переклади. Оформлення стилізоване, не є зображенням оригіналів. Пропозиції щодо часових зрізів для карт є завданнями до підручника/атласу, а не зображенням історичних кордонів.
